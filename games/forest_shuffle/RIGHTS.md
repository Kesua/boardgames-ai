Forest Shuffle © Lookout Games (designer: Kosch). This repository is an unofficial fan research project.

What is here: card names (for identification), card numbers and effects as structured data with short own-words
descriptions, rules summarised in own words (rules.md), engine code, trained models and statistics.
What is not here: rulebooks, card art, logos, copied card text.

Publisher notice: to be sent with the public launch (publish-game skill template); date and reply recorded here.
Removal on request: contact the maintainers (GitHub issue or the address in README.md); the game folder is removed
from main and the site rebuilt within 7 days. Git history keeps earlier files.
